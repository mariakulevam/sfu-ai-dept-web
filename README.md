# Сайт кафедры «Системы искусственного интеллекта»

Веб-интерфейс информационно-управляющей системы кафедры СИИ Института
космических и информационных технологий СФУ.

**Стек**: Django 5.1 (BFF) + Django Templates + Vanilla JS
**Архитектура**: Django выступает прослойкой между браузером и FastAPI-сервисом
команды (REST API). Своих моделей данных не имеет — все данные берутся из API.

## Запуск

### 1. Виртуальное окружение

```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка окружения

Скопируй `.env.example` в `.env` и укажи адрес FastAPI-бэкенда:

```bash
cp .env.example .env
```

В `.env`:

```
FASTAPI_ROOT_URL=http://127.0.0.1:8001
```

### 4. Миграции (нужны только для сессий Django)

```bash
python manage.py migrate
```

### 5. Запуск сервера

```bash
python manage.py runserver
```

Сайт открывается на `http://127.0.0.1:8000`.

## Реализованные страницы

**Публичные** (доступны без авторизации):

- `/` — главная: hero + последние объявления + ближайшие события
- `/about/` — о кафедре: миссия, направления подготовки
- `/staff/` — состав кафедры: карточки преподавателей

**Закрытые** (требуют входа в систему):

- `/login/`, `/logout/` — авторизация через JWT FastAPI
- `/profile/` — личный кабинет
- `/announcements/` — объявления с фильтрами по статусу
- `/announcements/<id>/` — карточка объявления
- `/events/` — события кафедры
- `/documents/` — документы по категориям
- `/schedule/` — расписание (сетка по дням)
- `/attendance/` — посещаемость (журнал + статистика)

## Фирменный стиль

Дизайн-система построена на **точной айдентике ИКИТ СФУ**:

- Основной цвет: `#1C9AD6` (голубой ракеты в логотипе)
- Акцентный цвет: `#4CC0AD` (изумрудные стрелки `</>`)
- Фирменный градиент: фиолетовый → голубой → изумрудный
- Шрифты: Noto Sans (основной), Inconsolata (моноширинные акценты, IT-вайб)
- Логотип ИКИТ во всех шапках и футерах

При этом сайт принадлежит кафедре «СИИ»: в шапке и футере используется
структура «Кафедра СИИ • ИКИТ • СФУ» — кафедра как часть института.

## Архитектура

```
Браузер ──→ Django (этот проект) ──→ FastAPI (бэкенд команды) ──→ PostgreSQL
                                  ↑
                                  ├── также ходит мобильное приложение (Flutter)
                                  └── также ходит Telegram-бот
```

Django получает HTTP-запросы от пользователя, через `core/services/api_client.py`
делает запросы к FastAPI, рендерит шаблоны и отдаёт HTML обратно.
JWT-токены хранятся в Django-сессии (HttpOnly cookie).
